# 目标冒溢节点的直接子汇水区连接（2026-10-24）

本次只补充目标节点直接接收的子汇水区编号与出口对应，不调整M1—M6的判断尺度、来源占比算法、峰值字段或拓扑调查范围。

## 证据位置

统一证据包 `evidence/evidence_package.json` 的事件 `local_structure` 记录中：

```json
{
  "metric_name": "local_structure",
  "object_type": "node",
  "object_id": "10",
  "event_id": "10:E001",
  "value": {
    "direct_subcatchments": [
      {"subcatchment_id": "2", "outlet_node_id": "10"}
    ]
  }
}
```

以上为Example1已有输入的连接示例，省略其他既有字段。连接来自本次运行冻结INP的 `[SUBCATCHMENTS]` 段，按Outlet列直接匹配事件目标节点。上游节点、其他节点、先流经其他子汇水区的编号不自动展开。输出没有面积、不透水率、入渗、洼蓄或LID参数。

## 进入LLM及引用

沿用现有首轮事件证据选择，整条 `local_structure` 记录送入 `visible_evidence`；不新增证据类别、对象类型或工具。诊断提示词的M1说明了两个字段的含义，并要求来源解释读取和使用相关编号。

子汇水区连接事实仍以目标节点及事件为断言对象，引用该事件 `local_structure` 的EvidenceID。来源占比引用 `direct_source_composition`，时间过程引用 `local_process_series`。多个直接汇水区共享的侧向入流汇总不自动拆分为各区贡献。

旧快照未提供此字段时，提示词不要求猜测编号。结构可用且列表为空表示没有直接连接的子汇水区；不表示没有其他直接输入。

## 使用

新构建的证据包会包含该字段；已有证据包和任务快照保持原样。使用旧模拟结果时，重新构建证据并创建新诊断任务即可使用新字段，无需重新水力模拟。已启动的服务需重启以载入更新后的代码与提示词。

离线检查覆盖直接连接筛选、多直接汇水区、排除上游／间接连接、无直接汇水区，以及选择和序列化后字段仍进入LLM输入并可通过现有引用绑定。在线LLM是否正确使用这些编号，留待下一次实际诊断确认。
